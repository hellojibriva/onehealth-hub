# provenance/

Cross-cutting provenance tracking for the research data layer:

- `SOURCES.md` — per-dataset citation, retrieval/access date, version, and
  license or usage restriction.
- `CHANGELOG.md` — version history of derived (`source-derived/` and
  `processed/`) datasets, and why each change was made.

Both files currently contain placeholder structure only — no source
citations have been added yet, since no datasets have been added yet.
