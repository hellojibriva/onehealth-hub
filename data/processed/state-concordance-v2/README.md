# processed/state-concordance-v2/

**Status: placeholder — no data added yet.**

Will hold Final State Concordance v2.0: state-level integration of WAHIS
animal-surveillance evidence and published-research evidence, covering all
Nigerian states plus FCT. Expected dimensions:

- spatial concordance
- temporal concordance (Yes / No overlap / Not assessable)
- species concordance (Yes / No match / Not directly comparable)
- research integration level (OHIAF)
- evidence-gap classification
- provenance

Per the project's scientific interpretation rules (see root `CLAUDE.md`),
this dataset must never be presented as a disease prevalence or risk map.
"No WAHIS record" and "no published study" indicate absence of a source
record, not absence of disease.

See `LINEAGE.md` in this directory for input/transformation documentation
(to be completed when the dataset is added).
