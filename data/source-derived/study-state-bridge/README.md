# source-derived/study-state-bridge/

**Status: placeholder — no data added yet.**

Will hold the study–state GIS bridge: one row per explicitly documented
study–state relationship, derived from the study evidence layer
(`data/source-derived/scoping-review/`) plus explicit study geography.

Rules that will govern this dataset once added:
- No invented geographic assignments — a study is linked to a state only if
  the source explicitly identifies that state.
- Multi-regional studies without individually documented states are **not**
  assigned to individual states. That uncertainty is preserved rather than
  resolved by assumption.

`data/dictionaries/` entry and `data/provenance/SOURCES.md` citation) in a
separate, explicitly approved step. Nothing here has been fabricated or
